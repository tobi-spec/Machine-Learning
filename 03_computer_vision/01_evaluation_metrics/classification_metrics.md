## Classification Metrics

# Accuracy

total correct predictions / total predictions

Problems with imbalanced classes. 
For example with 990 oranges and 10 apples and a model that classifies everything as orange would have a 
great accuracy


# Precision

total correct predictions in single class / total predictions in class
